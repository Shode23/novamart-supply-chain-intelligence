# Power BI Dashboard

This directory contains the final NovaMart Power BI report and dashboard screenshots.

The report includes seven main pages:

1. Executive Overview
2. Sales Performance
3. Product & Customer Performance
4. Inventory Intelligence
5. Procurement & Supplier Performance
6. Logistics & Service Performance
7. Financial & Operational Efficiency

The Power BI report also includes drill-through pages, tooltips, synchronized slicers, and validated DAX measures.
