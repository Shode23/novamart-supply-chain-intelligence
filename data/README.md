# NovaMart Dataset

The NovaMart project uses a simulated FMCG operational dataset created specifically for portfolio analysis.

The production dataset contains 14 relational tables covering:

- master data
- sales
- procurement
- inventory
- logistics
- finance

The full dataset is not required to review the analytical methodology, SQL modules, Power BI dashboard, or documented findings in this repository.

The database structure and major fields are documented in `docs/data-dictionary.md`.
