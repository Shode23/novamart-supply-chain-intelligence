# SQL Analysis Modules

This directory contains the six final SQL analysis modules used in the NovaMart Supply Chain Intelligence project.

1. `01_sales_performance.sql`
2. `02_product_customer_performance_v1.1.sql`
3. `03_inventory_intelligence_v1.0.sql`
4. `04_procurement_supplier_v1.0.sql`
5. `05_logistics_service_v1.0.sql`
6. `06_financial_operational_efficiency_v1.1.sql`

Each module is aligned to a specific analytical workstream and includes validation or reconciliation logic where appropriate.
